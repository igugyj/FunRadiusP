# 国际化模块

## 模块概述

国际化（i18n）模块是 FunRadiusP 的重要组成部分，负责提供多语言支持，让网站可以面向全球用户都能以自己的语言浏览网站。

### 功能特性

- 支持 6 种语言：中文（zh）、英文（en）、西班牙语（es）、日语（ja）、德语（de）、法语（fr）
- 使用 React Context 管理语言状态
- 支持浏览器语言自动检测
- localStorage 持久化用户语言偏好
- 支持环境变量配置默认语言
- 翻译文件模块化组织
- 支持参数化翻译
- 组件化支持

## 目录结构

```
lib/i18n/
├── index.ts                # 入口文件，导出公共 API
├── context.tsx            # 语言 Context 和 Provider（按需加载翻译）
├── utils.ts               # Language 类型 + 全量 translations（服务端 metadata 构建用）
├── format.ts              # getNestedValue / formatString 纯函数（无 JSON 依赖）
├── loader.ts              # 翻译按语言 dynamic import，zh 同步基线
├── defaults.json          # 翻译兜底默认值
└── translations/          # 翻译文件
    ├── zh.json            # 中文翻译（同步基线，进主 bundle）
    ├── en.json            # 英文翻译
    ├── es.json            # 西班牙语翻译
    ├── ja.json            # 日语翻译
    ├── de.json            # 德语翻译
    └── fr.json            # 法语翻译
```

## 语言类型定义

```typescript
export type Language = "zh" | "en" | "es" | "ja" | "de" | "fr";
```

## 核心 API

### LanguageProvider

**路径**: `lib/i18n/context.tsx

**功能**: 语言上下文提供者，提供语言状态管理

**Props**:
- `children`: React 子节点

**使用示例**:

```tsx
// app/layout.tsx
import { LanguageProvider } from '@/lib/i18n';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="zh-CN">
      <body>
        <LanguageProvider>
          {children}
        </LanguageProvider>
      </body>
    </html>
  );
}
```

### useLanguage Hook

**路径**: `lib/i18n/context.tsx

**功能**: 获取和设置语言状态的 Hook

**返回值**:
- `language`: 当前语言
- `setLanguage`: 设置语言的函数
- `t`: 翻译函数
- `availableLanguages`: 可用语言列表

**使用示例**:

```tsx
'use client';
import { useLanguage } from '@/lib/i18n';

export default function SomeComponent() {
  const { language, setLanguage, t, availableLanguages } = useLanguage();

  return (
    <div>
      <h1>{t('common.welcome')}</h1>
      <select value={language} onChange={(e) => setLanguage(e.target.value as any)}>
        {availableLanguages.map(lang => (
          <option key={lang}>{lang}</option>
        ))}
      </select>
    </div>
  );
}
```

### t() 翻译函数

**功能**: 根据键获取翻译文本

**参数**:
- `key`: 翻译键，支持嵌套（如 "common.home"）
- `params`: 可选参数对象，用于参数化翻译

**返回值**: 翻译后的字符串

**使用示例**:

```typescript
// 简单翻译
t('common.home');

// 参数化翻译
t('post.readingTime', { minutes: 5 });
// 输出："阅读时间：5 分钟"
```

## 翻译文件格式

翻译文件使用 JSON 格式，支持嵌套结构：

```json
{
  "common": {
    "home": "首页",
    "articles": "文章",
    "about": "关于"
  },
  "post": {
    "readingTime": "阅读时间：{minutes} 分钟",
    "publishedOn": "发布于 {date}"
  }
}
```

## 配置

### 环境变量

在 `.env.local` 中配置：

```env
NEXT_PUBLIC_DEFAULT_LANGUAGE=en
```

- `NEXT_PUBLIC_DEFAULT_LANGUAGE`: 默认语言，可选值：zh, en, es, ja, de, fr

## 语言初始化流程

1. **初始加载时：
   a. 检查 localStorage 中是否有保存的语言
   b. 如果有，使用保存的语言
   c. 如果没有，检测浏览器语言
   d. 如果浏览器语言支持，使用浏览器语言
   e. 否则使用环境变量配置的默认语言（默认 en
   f. 目标语言翻译按需加载：zh 同步可用，其余语言 dynamic import 对应 JSON chunk

2. **语言切换时：
   a. 更新语言状态
   b. 保存到 localStorage
   c. 异步加载目标语言翻译后更新
   d. 所有使用 t() 函数的组件会自动更新

## 最佳实践

### 1. 添加新的翻译键

在所有翻译文件中都要添加相同的键：

```json
// zh.json
{
  "newFeature": "新功能"
}
```

```json
// en.json
{
  "newFeature": "New Feature"
}
```

### 2. 参数化翻译

使用 {key} 语法：

```json
{
  "greeting": "你好，{name}"
}
```

使用：

```typescript
t('greeting', { name: '张三' });
```

### 3. 添加新的语言

1. 在 lib/i18n/utils.ts 中添加 Language 类型
2. 添加新的翻译文件
3. 在 lib/i18n/loader.ts 的 dynamicLoaders 中添加加载器
4. 在 lib/i18n/context.tsx 的 availableLanguages 中添加
5. 在 LanguageToggle 组件中添加国旗图标

### 4. 在服务器组件中使用

在服务器组件中，不能直接使用 useLanguage()，需要：
- 将数据从服务器组件中获取的数据作为 props 传递给客户端组件
- 在客户端组件中使用 useLanguage()

## 常见问题

### 1. 翻译不显示

- 检查翻译键是否正确
- 确认所有翻译文件中都有该键
- 检查键的路径是否正确

### 2. 语言切换不生效

- 确认 LanguageProvider 包裹了整个应用
- 检查是否在客户端组件中使用
