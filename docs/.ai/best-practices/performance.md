# 性能优化最佳实践

## 性能指标

### 核心 Web 性能指标

| 指标 | 描述 | 目标值 |
|------|------|--------|
| LCP (Largest Contentful Paint) | 最大内容绘制时间 | < 2.5 秒 |
| FID (First Input Delay) | 首次输入延迟 | < 100 毫秒 |
| TTI (Time to Interactive) | 可交互时间 | < 3.8 秒 |
| TBT (Total Blocking Time) | 总阻塞时间 | < 300 毫秒 |
| CLS (Cumulative Layout Shift) | 累积布局偏移 | < 0.1 |

### Next.js 性能指标

- **静态生成**: 页面在构建时预渲染，提高加载速度
- **代码分割**: 按路由和组件分割代码
- **预加载**: 自动预加载关键资源
- **图片优化**: 自动优化图片大小和格式

## 前端性能优化

### 1. 代码优化

#### 组件优化

- **React.memo**: 优化组件渲染，避免不必要的重渲染
- **useMemo**: 缓存计算结果，避免重复计算
- **useCallback**: 缓存函数引用，避免子组件不必要的重渲染
- **虚拟列表**: 对于长列表使用虚拟列表技术，如 `react-window`

#### 代码分割

- **动态导入**: 使用 `dynamic` 导入大型组件
  ```typescript
  import dynamic from 'next/dynamic';
  
  const HeavyComponent = dynamic(() => import('../components/HeavyComponent'));
  ```
- **路由级代码分割**: Next.js 自动按路由分割代码
- **组件级代码分割**: 按需加载大型组件

### 2. 资源优化

#### 图片优化

- **使用 Next.js Image 组件**: 自动优化图片大小和格式
  ```typescript
  import Image from 'next/image';
  
  <Image
    src="/images/example.jpg"
    width={500}
    height={300}
    alt="Example image"
  />
  ```
- **使用适当的图片格式**: WebP、AVIF 等现代图片格式
- **图片压缩**: 压缩图片大小，减少加载时间
- **懒加载**: 按需加载图片，减少初始加载时间

#### 字体优化

- **字体子集**: 只加载必要的字体字符
- **字体预加载**: 预加载关键字体
  ```html
  <link rel="preload" href="/fonts/font.woff2" as="font" type="font/woff2" crossorigin>
  ```
- **系统字体**: 优先使用系统字体，减少加载时间
- **字体显示策略**: 使用 `font-display: swap` 等策略

#### CSS 优化

- **Tailwind CSS**: 使用 Tailwind 的 JIT 模式，减少 CSS 文件大小
- **CSS 压缩**: 压缩 CSS 文件
- **关键 CSS**: 内联关键 CSS，减少渲染阻塞
- **CSS 代码分割**: 按需加载 CSS

### 3. 网络优化

#### 缓存策略

- **浏览器缓存**: 设置适当的缓存头
- **CDN 缓存**: 使用 CDN 缓存静态资源
- **Service Worker**: 缓存静态资源，支持离线访问
- **HTTP 缓存**: 合理使用 ETag 和 Last-Modified 头

#### 网络请求优化

- **减少请求数量**: 合并资源，减少网络请求
- **使用 HTTP/2**: 支持多路复用，减少连接开销
- **使用 HTTP/3**: 进一步优化网络传输
- **压缩传输**: 使用 Gzip 或 Brotli 压缩传输内容

#### 预加载和预取

- **预加载**: 预加载关键资源
  ```html
  <link rel="preload" href="/api/data" as="fetch">
  ```
- **预取**: 预取可能需要的资源
  ```html
  <link rel="prefetch" href="/next-page">
  ```
- **预连接**: 预连接到关键域名
  ```html
  <link rel="preconnect" href="https://api.example.com">
  ```

## 本项目实测优化要点（2026-05-01）

- **KaTeX CSS 按需加载**：根 layout 不再全局外链 katex.min.css（渲染阻塞 + 跨域）。MathStyles 组件检测 .katex 元素后注入同源 /katex/katex.min.css，样式由 copy-assets 构建时从 node_modules 自托管
- **Live2D 懒加载**：oh-my-live2d 锁版本 0.19.3，requestIdleCallback 空闲加载，触屏设备跳过；避免每页拉 CDN 脚本
- **动态分包**：Live2DWidget / Particles 经 next/dynamic + ssr:false 拆出首屏 bundle，粒子库 natural-falling-js 按需加载
- **事件节流**：Header 的 scroll/mousemove 用 requestAnimationFrame 节流，避免高频 setState 引发重渲染

## 常见性能问题

### 1. 页面加载缓慢

- **原因**: 资源过大，网络请求过多，服务器响应慢
- **解决方案**: 优化资源大小，减少网络请求，优化服务器响应

### 2. 交互卡顿

- **原因**: JavaScript 执行时间过长，DOM 操作频繁
- **解决方案**: 优化 JavaScript 代码，减少 DOM 操作，使用防抖和节流

### 3. 布局偏移

- **原因**: 图片未设置尺寸，动态内容加载
- **解决方案**: 为图片设置尺寸，使用占位符，预加载关键资源

### 4. 内存泄漏

- **原因**: 未清理的事件监听器，循环引用
- **解决方案**: 正确清理事件监听器，避免循环引用，使用 WeakMap 和 WeakSet
